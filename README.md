# 🌐 Nedd Digital Website  

A professional business website for **Nedd Digital**, a company offering **QuickBooks + Power BI** solutions.  
The website is built with **Tailwind CSS** for modern responsive UI and **Firebase Firestore** for storing & managing testimonials.  
Deployed on **Netlify** for fast and reliable hosting.  

🔗 **Live Demo** → [Nedd Digital Website](https://nedddigital.netlify.app/)  

---

## ✨ Features  

✅ Responsive multi-page design with Tailwind CSS  
✅ Dynamic testimonials powered by Firestore  
✅ Service pages for QuickBooks & Power BI solutions  
✅ Contact form with WhatsApp & Email integration  
✅ Proposal request page for clients  
✅ Fast & secure deployment with Netlify  

---

## 🛠️ Tech Stack  

- **Frontend**: HTML5, Tailwind CSS, JavaScript  
- **Backend / Database**: Firebase Firestore 🔥  
- **Hosting**: Netlify 🚀
